# 附近机会雷达 · 西安活动目录

**[打开网站](https://victkk11-beep.github.io/nearby-social-radar-site/)**

这里汇集西安交通大学及西安本地公开渠道中的讲座、比赛、志愿、展览、实习等机会，帮助学生发现原本分散的活动信息。可在手机或电脑上搜索、筛选，并从活动卡片返回原始公告核对详情。

## 数据如何更新

- 私有源码仓库的 GitHub Actions 每天北京时间 03:17 尝试采集一次，并发布公开活动快照；网站会显示最近成功同步时间和异常状态。
- 来源失败时可能继续显示尚未结束的旧活动。报名截止、地点、参与资格和费用请以原始发布方的页面为准。
- 本仓库只保存静态网站和可公开的活动数据，不包含用户账号、个人收藏、笔记、个人位置或服务端密钥。

本仓库由自动发布流程维护。主应用源码与采集规则保存在私有仓库，因而这里不是完整的 Next.js 项目源码。公开站的地图功能依赖当前发布配置；即使地图不可用，仍可使用列表、搜索和原文链接。
